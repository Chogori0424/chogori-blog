# Chogori Blog

Chogori Lee 的个人技术博客，基于 Astro 官方 blog 模板搭建。

## 站点信息

- 域名：<https://chogori.xyz>
- 技术栈：Astro
- 包管理器：npm
- 部署目标：Vercel
- 内容格式：Markdown / MDX

## 内容方向

- 网络代理：Surge、Quantumult X、代理规则维护与网络调试
- 工程制造：Siemens NX/UG、模具工艺和工程经验
- 音频设备：耳机、播放器、桌面音频链路和听感记录
- 个人日志：技术折腾、建站过程和长期写作计划

## 常用命令

```bash
npm install
npm run dev
npm run build
npm run preview
```

## 目录说明

- `src/content/blog/`：博客文章，支持 Markdown 和 MDX
- `src/pages/`：页面和路由
- `src/pages/categories/`：栏目归档页
- `src/layouts/`：文章布局
- `src/components/`：通用组件
- `src/consts.ts`：站点基础信息和栏目配置
